# Evidence

Every row in these tables was checked against the cited page on the verification date shown. Where a full report sits behind a registration wall, figures come from the publisher's own press release or landing page and this is noted. Analyst research notes that could not be accessed are not cited; only their public press releases are.

Each source is tagged with the claim type it can legitimately support: task efficiency, team productivity or capacity, cost avoidance, or hard-dollar saving. Self-reported figures are never used as measured ones.
