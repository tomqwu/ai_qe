# Economics

Productivity is not a saving. The pages in this section keep the four levels apart (task efficiency, capacity released, hard-dollar saving, total software-spend impact), show how a questionnaire and a pilot feed a preliminary waterfall without false precision, and record the exact language that can and cannot be used on an executive slide.
