04 / Two initial workflow integrations

Build thin integrations around
existing systems of record.

Workflow A / Failed-test triage

From failure to a reviewed cause

  1. Collect scoped CI failure context.
  2. Draft a cause classification with evidence.
  3. Have a reviewer accept or correct it.
  4. Record active effort and classification accuracy.

Workflow B / Test generation

From specification to a tested draft

  1. Read API specs and existing test patterns.
  2. Generate candidate component or API tests.
  3. Run tests and security checks; review changes.
  4. Record acceptance, coverage and later rework.
Optional AppSec extension: contextual SAST/SCA triage and draft fixes, with sampled audits of dismissed findings.

06 / Measurement architecture

Instrument the human work
as well as the model call.

Establish the baseline

Capture activity effort and two quarters of delivery, defect and security data. Record task complexity and developer experience.

Link the workflow events

Connect each task to source context, prompt / model version, draft artifact, reviewer decision, CI result and AI cost.

Compare like with like

Alternate sprints or squads where feasible. Otherwise compare the same squad to its baseline and record confounders.

Measure active effort separately from elapsed time. Include preparation, review, correction and controls.

07 / Proposed pilot promotion gate

Promote on measured value
within the control boundary.

≥15%

Net effort saving

On at least one selected use case, after review and control effort.

≥50%

Actual adoption

Share of eligible tasks using the capability during the pilot.

Within cap

Operating cost

AI cost remains under its ceiling, with a Finance-confirmed capture route.

All floors must hold

Quality and security remain within agreed baseline limits. A floor breach pauses the pilot; a control incident, no capture route or <10% saving on both use cases is a stop signal.

Pilot criteria, not achieved results. Savings from 10% to below 15% require sponsor review.

08 / Architecture to delivery

Implement the smallest
complete, measurable workflow.

First / Define

Agree the contracts

Select applications and use cases. Confirm data, identity, approved platform, owners and baseline.

Then / Integrate

Connect one vertical slice

Carry a task from scoped context to a reviewed artifact, with CI evidence and telemetry.

Next / Validate

Earn the expansion

Test net value and floors. Revalidate successful capabilities across teams and releases.

Architecture review output: a boundary diagram, workflow owner, control evidence plan and measurement contract.
